# Dr Johnjohnson Dental Practice website

## Pages

- `index.html` — home page with Sign In and Sign Up tabs
- `about.html` — practice story, mission and vision

- `services.html` — service cards with links to preselect a treatment
- `appointment.html` — validated appointment request form and local demo list

- `contact.html` — validated contact form
- `clientsReviews.html` — sample reviews and review submission

## How to run
Keep the folder structure intact. 
Open `index.html` in a browser, or upload the complete folder to a static host such as Netlify or GitHub Pages.

## Important demo limitations
This is a frontend coursework demonstration. Local browser storage is used for demo accounts, appointment requests and reviews.

Data is not shared between devices or sent to the practice. 
The sample sign-in system stores a password in browser storage and is **not secure authentication**.

Do not use real passwords or real patient information. 
A production website must use secure server-side authentication, a database, HTTPS, and a privacy-compliant booking/contact system. 

Contact form submission currently validates but does not send email.
Replace placeholder contact details before publishing.

## SEO included
Each page has a unique title and meta description, a viewport declaration, semantic headings, accessible form labels, and internal links. 
Add real business details and a sitemap/Search Console setup when ready.
